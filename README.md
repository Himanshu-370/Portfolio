# Himanshu Singh — Portfolio

Personal portfolio website built with Next.js 15, React Three Fiber, and Framer Motion.

**Tech Stack:** Next.js 15 · React 19 · TypeScript · Tailwind CSS · React Three Fiber · Framer Motion

## Features

- Interactive 3D hero with a wireframe torus and floating particles
- Smooth scroll animations powered by Framer Motion
- Responsive design with mobile navigation
- Contact form via Formspree
- Fully dark-themed UI with shadcn/ui components

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
pnpm start
```
